# ❤️ Heart Disease Prediction Using Machine Learning

A Machine Learning web application built using **Python, Scikit-learn, and Streamlit** to predict the risk of heart disease based on user-provided health information.

The application uses a trained K-Nearest Neighbors (KNN) model to generate predictions through an interactive web interface.

## 🚀 Features

- Interactive Streamlit web application
- Heart disease risk prediction using a trained KNN model
- User input for age, sex, cholesterol, fasting blood sugar, chest pain type, resting ECG, oldpeak, and ST slope
- Data preprocessing using a saved scaler
- Saved Machine Learning model loading using Joblib
- Simple and user-friendly interface

## 🛠️ Tech Stack

- **Python** – Programming language
- **Pandas** – Data manipulation
- **Scikit-learn** – Machine Learning and preprocessing
- **Joblib** – Saving and loading trained models
- **Streamlit** – Web application development

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd Heart_project
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the virtual environment

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Windows Command Prompt:**

```cmd
.venv\Scripts\activate.bat
```

### 4. Install dependencies

```bash
python -m pip install streamlit pandas scikit-learn joblib
```

## ▶️ Run the Application

Start the Streamlit application:

```bash
python -m streamlit run app.py
```

The application will open in your browser.

Default local address:

```text
http://localhost:8501
```

## 🧠 Machine Learning Model

The project uses the **K-Nearest Neighbors (KNN)** classification algorithm.

### Input Features

- Age
- Sex
- Chest Pain Type
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Oldpeak
- ST Slope

### Prediction

The application collects user input, prepares the input data, applies preprocessing, and passes it to the trained model.

The application displays the model's prediction:

- High Risk of Heart Disease
- Low Risk of Heart Disease

## 📊 Model Files

The project uses the following saved files:

| File | Description |
|---|---|
| `KNN_heart.pkl` | Trained KNN model |
| `scaler.pkl` | Saved feature scaler |
| `heart_columns.pkl` | Expected feature columns |
| `columns.pkl` | Additional saved column information |

These files must be compatible with the preprocessing and feature structure used during model training.
